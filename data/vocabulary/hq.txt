// The categories are "noun", "verb", "prep", "adj", and "other".
//
// The pattern is:
//
//				chapter#category#Greek#English
//
// In the Greek field, different forms are separated by ";".
//
// So…
//
// 		ἐκ + gen; ἐξ + gen
//
// In the English field, different forms are separated by ";". So…
//
//			and; even; also
//
// Items in category "noun" follow the pattern 
// "nominative form, comma, genitive form, comma, 
// definite article (to show gender)":
//
//			ἀγορά, ἀγορᾶς, ἡ
//
// Verbs include all principal parts, in this 
// pattern (number, space, principal-part, semicolon):
//
//			1 πέμπω;2 πέμψω;3 ἔπεμψα;4 πέπομφα;5 πέπεμμαι;6 ἐπέμφθην
//
// A verb may have fewer than six. The missing ones are 
// omitted in the list, but the numbering of principal 
// parts follows the traditional scheme where "1" is 
// "present active indicative" and "6" is "aorist passive":
//
//			1 θάπτω;2 θάψω;3 ἔθαψα;5 τέθαμμαι;6 ἐτάφην
//
// A verb may have more than one form of a numbered 
// principal part:
//
//			1 βλάπτω;2 βλάψω;3 ἔβλαψα;4 βέβλαφα;
//			5 βέβλαμμαι;6 ἐβλάβην;6 ἐβλάφθην
//
// Phase 4 — per–principal-part English (preferred for verbs):
//
//   Split Greek / numbered-English fields (NOT the combined
//   “1 λύω, I unbind” style). Greek stays as above; English uses
//   the same N-prefix so each gloss belongs to one PP. Multiple
//   glosses per PP number are allowed:
//
//     2#verb#1 λύω;2 λύσω;3 ἔλυσα;4 λέλυκα;5 λέλυμαι;6 ἐλύθην#1 I unbind;1 I free;2 I will unbind;2 I will free;3 I unbound;3 I freed;4 I have unbound;4 I have freed;5 I have been unbound;5 I have been freed;6 I was unbound;6 I was freed
//
// Legacy one-gloss / multi-gloss English without leading “N ”
// (e.g. “unbind; free”) is still accepted by the parser and
// applies the same English to every PP of that verb.
//
// Migration status: nearly all HQ verbs use numbered English.
// Verbs without numbered Greek PPs (e.g. ἀποδέχομαι) keep legacy
// English. Regenerate with:
//   julia --project=. scripts/migrate_pp_english.jl
//
// Phase 5 — preposition + case senses:
//
//   Preferred legacy (one line per case sense; parser extracts case):
//
//     2#prep#παρά + gen#from beside
//     2#prep#παρά + dat#at the side of; at the house of
//     2#prep#παρά + acc#to the side of; beside; contrary to
//
//   Case tokens: gen|dat|acc (also genitive|dative|accusative; optional
//   trailing period). Alternate Greek forms of the same case stay on one
//   line, separated by ";":
//
//     1#prep#ἐκ + gen; ἐξ + gen#from; out of
//
//   Optional consolidated form (case-tagged English, lemma-only Greek):
//
//     2#prep#παρά#gen from beside; dat at the side of; acc beside
//
//   Both formats set lemma + prep_case on VocabItems for case-sense drills.
//   Config: prep_case_fraction / prep_case_max_count (default off).
//
